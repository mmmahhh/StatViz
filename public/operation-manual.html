StatViz 操作手册

适用对象：质量工程师、工艺工程师、检验员。本文用于指导日常使用箱线图、MSA、Kappa、线性与偏移等功能。

1. 快速开始

  1. 点击左侧或首页中的 导入数据集 (.csv, .xlsx)。
  2. 导入 Excel 或 CSV 文件。
  3. 在左侧 数据列 中，将字段拖入 X 轴 和 Y 轴。
  4. 若原始数据按日期记录，可开启左侧 日期分组，按月自动生成类似 3月外径D1 的分组。
  5. 点击右上角 运行分析。
  6. 查看图表、统计摘要和正式报告摘要。

2. 常用分析场景

同规格批次对比

  • 先在左侧模板中指定 规格列 和 规格值
  • X 轴：生产批次
  • Y 轴：检测值
  • 用途：如 0402 与 0403 批次比较

优品 / 劣品对比

  • X 轴：质量判定
  • Y 轴：检测值
  • 用途：比较优品与劣品中位数和波动范围

单批次 vs 大批次区间

  • 当前数据集：筛选单一批次，如 0402
  • 对比数据集：区间映射，如 0320-0330
  • 在图表顶部选择 对比数据集
建议优先使用左侧的“业务快速模板”功能，可减少手工输入筛选条件。

3. MSA 相关功能

MSA - 计量型 (Gage R&R)

  • X1：零件
  • X2：操作员
  • Y：测量值

MSA - 计数型 (Kappa)

  • X1：坩埚编码
  • X2：评估员
  • Y：判定结果

MSA - 线性与偏移

  • X：参考值
  • Y：测量值

4. 导出与分享

  • 导出为图片 (PNG)：适合发消息、贴汇报。
  • 导出完整报告 (PDF)：适合发同事、归档。
  • 导出统计结果 (CSV)：适合二次分析。

5. 注意事项

  • 大文件分析主要依赖浏览器性能，建议优先清洗无关列。
  • MSA 计量型要求平衡数据，若各组合重复次数不一致，系统会拒绝计算。
  • Kappa 分析适用于属性判定数据，不适合数值型测量值。
  • 若想做单批次与历史大区间对比，建议使用两个数据集分别筛选后再比较。
