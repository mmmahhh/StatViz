# 欧晶业务样例数据

以下样例用于快速验证 `StatViz` 中与你当前业务最接近的分析流程。

## 文件说明

- `OJ_batch_0402_vs_0403.csv`
  - 用途：同规格批次之间箱线图对比
  - 建议设置：
  - X 轴：`生产批次`
  - Y 轴：`检测值`

- `OJ_quality_good_vs_crack.csv`
  - 用途：优品 vs 劣品对比
  - 建议设置：
  - X 轴：`质量判定`
  - Y 轴：`检测值`
  - 可进一步用 `生产批次` 或 `规格` 做筛选

- `OJ_batch_single_vs_range.csv`
  - 用途：单一批次 vs 大批次区间对比
  - 建议操作：
  - 在当前数据集用“业务快速模板”把 `生产批次=0402` 筛出来
  - 另一个数据集用 `生产批次 range 0320,0330` 并设置别名为 `大批次_Benchmark`
  - 然后在图表顶部使用“对比数据集”做箱线图比较

- `OJ_msa_kappa_judgement.csv`
  - 用途：产品一致性 Kappa 分析
  - 建议设置：
  - 模块：`MSA - 计数型 (Kappa)`
  - X 轴第一列：`坩埚编码`
  - X 轴第二列：`评估员`
  - Y 轴：`判定结果`

- `OJ_msa_linearity_bias.csv`
  - 用途：线性与偏移分析
  - 建议设置：
  - 模块：`MSA - 线性与偏移 (Linearity)`
  - X 轴：`参考值`
  - Y 轴：`测量值`

## 说明

- 这些数据是演示样例，不代表真实工艺能力极限。
- 主要目标是帮助你快速验证：
  - `0402 vs 0403`
  - `优 vs 劣`
  - `0402 vs 0320-0330`
  - `Kappa`
  - `线性与偏移`
