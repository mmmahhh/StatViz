# External Integrations

**Analysis Date:** 2026-04-17

## APIs & External Services

**LLM Analysis Services:**
- OpenAI - AI-powered statistical insight generation
  - Endpoint: OpenAI API (default) or custom base URL
  - Auth: API key stored in browser localStorage
  - Purpose: Deep quality diagnostics, statistical interpretation, anomaly analysis

- DeepSeek - Alternative LLM provider
  - Endpoint: DeepSeek API
  - Auth: API key in localStorage
  - Purpose: Same as OpenAI, used as fallback/alternative

- MiniMax (abab6.5s) - Chinese-optimized LLM provider
  - Endpoint: MiniMax API
  - Auth: API key in localStorage
  - Purpose: Enhanced support for Chinese text analysis

- SiliconFlow - Cost-effective LLM provider
  - Endpoint: SiliconFlow API
  - Auth: API key in localStorage
  - Purpose: Budget-friendly alternative for statistical analysis

**Implementation:**
- No LLM integration code is present in the codebase (Note: README mentions AI features but actual implementation files deleted from git status: `D src/utils/aiAnalyst.ts`)
- Intended to support OpenAI-compatible API format (base URL configurable)
- Configuration stored in `src/components/settings/` (file deleted in current state)

## Data Flow

**User Workflow:**
1. User uploads CSV/Excel file via file input
2. File parsed locally using PapaParse or SheetJS
3. Data stored in Zustand global state (useDataStore)
4. User configures dimensions (X-axis, Y-axis, color coding)
5. User runs analysis:
   - Statistical calculations performed locally (jstat, simple-statistics)
   - Chart generated with D3.js
   - (Optional) AI analysis sent to configured LLM provider
6. Results rendered in UI
7. Export options: PNG (html2canvas), CSV (string), PDF (jsPDF)

**No External Dependencies in Data Flow:**
- All statistics calculated in-browser
- All charts rendered client-side
- All exports generated locally
- LLM integration is optional add-on (code currently deleted)
